MTG Winget Source

This endpoint is a private Winget REST source for Midtown Technology Group internal tools.

winget source add -n mtg-tools -a https://winget.midtowntg.com/api -t Microsoft.Rest
winget source update mtg-tools
winget install MidtownTechnologyGroup.Voquill

WinGet selects this source only for packages it publishes, so winget install 7zip.7zip still comes from the public source. The feed is anonymous; keep the source implicit so discovery can pick it per package.
