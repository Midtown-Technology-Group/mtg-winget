MTG Winget Source

This endpoint is a private Winget REST source for Midtown Technology Group internal tools.

winget source add -n mtg-tools -a https://winget.midtowntg.com/api -t Microsoft.Rest --explicit
winget source update mtg-tools
winget install --id MidtownTechnologyGroup.Voquill --source mtg-tools

Register the source with --explicit so ordinary WinGet commands never query it; name it with --source mtg-tools for Midtown packages only.
